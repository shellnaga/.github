<h3 align="center">shell'naga_</h3>
<p align="center">The native terminal and SSH client for Windows 11 and Linux, written in Rust. Free, no account.</p>

Tabs and split panes; on Windows, WSL, PowerShell, Git Bash and cmd in one window, on Linux an AppImage; a native SSH client with jump hosts, SFTP,
mosh and tmux; drawn on the GPU.

Shell'Naga is closed-source software under its [license agreement](https://shellnaga.sh/eula). The
[feedback](https://github.com/shellnaga/feedback) repository carries the release notes, the installers and the
issue tracker. Contact: support@shellnaga.sh.
